# Architecture decisions

Architecture decisions are short records of choices that are expensive to reverse. Each record states the context, the decision, the consequences, and the alternatives.

## Template

```md
# NNNN: Title

- Status: Proposed | Accepted | Superseded
- Date: YYYY-MM-DD
- Deciders: Names
- Related: Links

## Context

What problem or constraint forced a decision?

## Decision

What did we choose?

## Consequences

What becomes easier, harder, or newly required?

## Alternatives considered

What else was on the table, and why was it rejected?
```
